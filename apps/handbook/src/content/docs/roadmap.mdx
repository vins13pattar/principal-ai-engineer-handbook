## Current version: v0.1.0 — Platform foundation

The documentation platform is complete: the Astro + Starlight site, the shared component and
diagram libraries in `packages/`, the pnpm workspace layout, linting/formatting/testing, and CI/CD.
Everything after this point is content, authored incrementally against that platform.

## How this roadmap works

Each version bump ships complete modules, not partial ones — a module isn't "in progress" on this
roadmap, it's either published (with every required section from the [Learn](/Principal-AI-Engineer-Interview-Handbook/learn/) structure)
or not started. `scripts/lint-content-structure.ts` enforces that a merged module page has every
required section, so the roadmap can't silently drift from what's actually on the site.

Track progress against this roadmap through the repository's
[releases](https://github.com/vins13pattar/Principal-AI-Engineer-Interview-Handbook/releases) and
[commit history](https://github.com/vins13pattar/Principal-AI-Engineer-Interview-Handbook/commits/main).
