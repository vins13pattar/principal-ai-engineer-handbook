Cheat sheets are the one-page version of a [Reference](/reference/) lookup or [Learn](/learn/)
module — dense enough to tape next to a monitor, plain enough to print in black and white. This
site's print stylesheet hides navigation chrome automatically, so `Cmd/Ctrl+P` on any cheat sheet
produces a clean page.

## Planned sheets

No cheat sheets are published yet — see the [Roadmap](/roadmap/) for the authoring schedule. They
will track the same topics as [Reference](/reference/) once those lookups exist, condensed to a
single printable page each.
