Reference pages are quick lookups, not tutorials — the thing you open mid-design-review to check
Raft's exact leader-election timeout behavior, not the thing you read start to finish. Each one is
short, dense, and link-rich back to the [Learn](/learn/) module or [Architecture](/architecture/)
page that goes deeper.

Every lookup has the same five sections, enforced in CI: **At a Glance**, **Key Concepts**,
**Numbers That Matter**, **Common Gotchas**, and **Where to Go Deeper**. The shape is deliberately
narrow — those are the four questions a lookup actually gets opened for, plus the route back into
the deeper material. Anything that needs more than that belongs in a Learn module.
