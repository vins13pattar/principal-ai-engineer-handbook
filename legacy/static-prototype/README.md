# Static-HTML prototype (retired)

This is the original hand-written HTML/CSS/JS version of the handbook — the site that existed
before the [Astro + Starlight documentation platform](/apps/handbook) replaced it (see
[ADR-0001](https://principal-ai-engineer-handbook.pages.dev/adr/decisions/0001-astro-starlight-platform/)).

It's kept here, unmodified, as source material for migrating its content — Module 0 (Principal
Engineer Mindset), Module 1 (Production Python), the start of Module 2 (Distributed Systems), and
the AI infrastructure interview playbook — onto the new platform. See the
[Learn section overview](https://principal-ai-engineer-handbook.pages.dev/learn/)
and [Roadmap](https://principal-ai-engineer-handbook.pages.dev/roadmap/) for
the migration schedule.

Do not add new content here or link to it from the live site — it's a reference snapshot, not a
published section.
